# Rule: STRUCTURE.md Maintenance

## Context
`STRUCTURE.md` is a hand-curated map of this repository. It is used to prevent unnecessary file-tree listing and to ensure architectural consistency.

## Required Actions
1. **Always Consult:** Use `STRUCTURE.md` to orient yourself before performing `ls` or `find` commands.
2. **Mandatory Update:** Any task that modifies the file structure (creating/deleting/renaming) is not "Done" until `STRUCTURE.md` is updated.
3. **Comment Consistency:** Maintain the `#` comment style and the ASCII tree format.
4. **No Redundancy:** Since `STRUCTURE.md` exists, do not output long file trees in the chat unless specifically asked.
